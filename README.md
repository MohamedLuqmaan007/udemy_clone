# Udemy Clone Website

## About the Project
This project is a front-end clone of the Udemy website, created using HTML and CSS. It recreates the layout of an online learning platform, including the navigation bar, course cards, category sections, promotional banner, and footer.

## Features
- Navigation bar with search box
- Login and Sign-up buttons
- Promotional sale banner
- Course cards with images, ratings, and prices
- Premium and Best Seller labels
- Trending courses section
- Company banner
- Footer with useful links
- Responsive layout improvements using CSS Flexbox

## Technologies Used
- HTML5
- CSS3
- Google Fonts
- Font Awesome icons
